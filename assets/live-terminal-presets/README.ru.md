# Living Forge

Единственный новый встроенный живой набор для CanvasTTY 2.0. Living Forge, preview.5: исходная графика Volcanic Forge с различимыми состояниями.

Пиксельные GIF: 48 кадров, 10 кадров/с, цикл 4,8 с. Девять рамок: minimal/detailed/master × idle/working/completed; отдельный фон. Камера и каменные детали неподвижны, анимируются локальные потоки лавы, огонь и искры. ZIP содержит измеренные проёмы и площадки штатных кнопок в layout.json. Профиль дополнительно включает живой фон Canvas, аватар и часы.

Idle: тлеющие каналы, знак паузы, IDLE. Working: яркая лава, покадровый молот, WORKING. Completed (Done): остывшие бирюзовые каналы, галочка, DONE. Символы и подписи остаются видимыми при паузе. Геометрия minimal/detailed/master сохраняется; состояния отличаются рисунком, цветом и движением, а не одной фазой огня.

У набора стабильный ID; перезапуск не создаёт копии. При изменении встроенного ZIP тема обновляется по SHA-256 с сохранением ID и выбора пользователя. Предыдущие файлы сохраняются в pixel-skins/.retired. Прежние экспериментальные Aurora, Ember и Sakura исключены из сборки. Их установленные копии с известными встроенными ID при обновлении сохраняются там же и исчезают из списка; пользовательские импортированные темы сохраняются.

Для повторной сборки состояний из утверждённых сцен используется tools/build_forge_states.py в design-engine: вход содержит scenes/, roles/, Volcanic-Forge/; выход — новая папка. Проверяются живые GIF, прозрачный проём и визуальные отличия первых кадров всех пар состояний.

Исходная графика создана для проекта с ImageGen, анимация собрана локальным покадровым движком. Настройка остановки анимации и системное уменьшение движения поддерживаются штатным Live Engine.
