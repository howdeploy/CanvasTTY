# Living Forge — полный профиль

Единственная новая тема этой сборки. Девять GIF-рамок: minimal/detailed/master × idle/working/completed. Камера неподвижна; огонь, лава, искры и молот движутся по пикселям. Idle — тление/пауза, Working — оранжевая лава/молот, Done — бирюзовые каналы/галочка.

Терминальная тема входит во встроенный каталог. Отдельные пакеты Canvas, аватара и часов можно импортировать через мастерскую обоев в настройках внешнего вида. Это три независимых файла .ctwallpaper.

Для проверки целого профиля на исходниках, из корня репозитория:

```sh
node design-engine/tools/prepare_lab_profile.mjs . assets/living-forge-profile/preset.json /absolute/path/to/NEW-profile
```

Нужен новый каталог профиля. Скрипт отказывается менять существующий. Затем запустите отдельную тестовую сборку с CANVASTTY_USER_DATA_DIR, указывающим на этот каталог. Запущенные рабочие профили не редактируйте.

Манифест содержит SHA-256 всех пакетов, параметры проёмов, оформления и таймеров. Это набор для ручного импорта и тестовой подготовки; единого пользовательского импортера полного профиля в приложении пока нет.
