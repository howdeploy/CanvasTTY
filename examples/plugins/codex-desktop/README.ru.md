# Codex Desktop для CanvasTTY

Отдельный плагин от **bbutterm** по идее
[Hermes HUD](https://github.com/howdeploy/canvastty-plugin-hermes-hud).
Показывает настоящее окно запущенного Codex/ChatGPT Desktop внутри карточки канваса.

Нужны Windows 10/11 и сборка CanvasTTY с расширением SDK `desktop:embed` из этого
изменения. Обычная версия 1.8.4 этот API не поддерживает. Приложения должны работать
от одного пользователя, с одинаковыми правами и режимом DPI.

1. Установите папку плагина через Developer plugins либо опубликуйте её содержимое
   в корне `bbutterm/canvastty-plugin-codex-desktop` и установите по ссылке GitHub.
2. Проверьте разрешение на просмотр заголовков и встраивание desktop-окон.
3. Откройте карточку Codex Desktop через список расширений или HOME-виджет.
4. Запустите Codex/ChatGPT Desktop обычным способом. Нажмите «Обновить», выберите
   окно и нажмите «Встроить окно».
5. «Вернуть на рабочий стол» восстанавливает окно, не закрывая приложение.

Закрытие карточки, отключение плагина и нормальный выход из CanvasTTY тоже возвращают
окно. Настройки и меню CanvasTTY временно скрывают native-содержимое. Управление
клавиатурой и колесом внутри окна остаётся у Codex; двигайте канвас за фон и рамку.

Функция экспериментальная: GPU-поверхности и собственные диалоги приложений могут
работать иначе. При разных режимах DPI встраивание отклоняется до изменения окна.
При масштабировании канваса интерфейс приложения перестраивается под размер окна,
а не масштабируется как картинка. Автоматического запуска/завершения процессов и
автоматического встраивания после перезапуска нет. Ключи и сеть плагину не нужны.

Полное описание и ограничения: [English README](README.md).
