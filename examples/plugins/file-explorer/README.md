# Canvas Files

Проводник для CanvasTTY: карточка в канвасе и отдельное окно предпросмотра.

- Навигация по выбранным папкам, назад/вперёд/вверх, фильтр по имени, скрытые файлы.
- Список и плитки; большие каталоги загружаются страницами по 200 элементов.
- Перетаскивание файла или папки в терминал вставляет экранированный путь без Enter.
- PNG, JPG/JPEG, GIF, WebP, AVIF, BMP, SVG; потоковые видео и аудио с перемоткой.
- MP4/M4V, MOV, WebM, OGV; MP3, WAV, OGG/Opus, FLAC, M4A, AAC — при поддержке кодека в Electron.
- Текст и код — безопасный предпросмотр первых 256 КиБ.
- Изображения, видео, аудио и текст открываются также отдельным окном; кнопка «Показать в проводнике» вызывает Finder, Windows Explorer или файловый менеджер Linux.

Плагин использует только `storage` и новое разрешение `files:read`. Он не требует
Node.js в веб-странице, сети или доверенного нативного сервиса. Доступ выдаётся
отдельно к папкам через системный диалог. Убрать папку можно кнопкой × рядом с ней.
Доступ к символическим ссылкам за пределами выбранной папки запрещён.

## Совместимость и установка

Текущий пакет требует прилагаемых изменений хоста CanvasTTY (`files:read`,
`canvastty-files` и обработчик перетаскивания). На исходной сборке 1.8.5-beta.1
без патча установка не сработает: хост отклонит неизвестное разрешение.

1. Применить патч к исходникам CanvasTTY и собрать приложение.
2. Поместить содержимое этой папки в корень отдельного GitHub-репозитория:
   `canvastty.plugin.json` должен находиться именно в корне.
3. В собранном CanvasTTY открыть «Настройки → Расширения» и установить плагин
   по HTTPS-ссылке этого репозитория; подтвердить показанные разрешения.
4. Открыть вкладку Files в канвасе и нажать «Выбрать папку».

Автоматической публикации и установки в основной профиль пользователя нет.
Локальная тестовая сборка использует отдельный профиль и подготовленные тестовые файлы.

## Управление

Один клик выбирает файл и показывает предпросмотр. Двойной клик или Enter
открывает папку либо отдельное окно. Для папки также есть явная кнопка
«Открыть папку». Стрелки выбирают соседний файл;
Backspace / Alt+↑ — на уровень выше; Alt+← / Alt+→ — история;
Ctrl+F / Cmd+F — фильтр текущего каталога.

После 30 минут дескриптор перетаскивания истекает — обновите каталог кнопкой ↻.
Кавычки для пути соответствуют стандартной оболочке хоста: POSIX на macOS/Linux,
PowerShell на Windows. Для cmd.exe, WSL и вложенных оболочек может понадобиться
другая форма пути/кавычек. Это перетаскивание внутри CanvasTTY; перенос файлов
в сторонние приложения средствами ОС в этой версии не реализован.

Проигрыватель использует декодеры Electron, поэтому поддержка контейнера
не гарантирует поддержку любого кодека. Для неподдерживаемых файлов доступна
кнопка системного проводника. PDF и офисные
документы не имеют встроенного проигрывателя/рендерера. Копирование, перенос,
переименование и удаление файлов не входят в эту версию.

## Проверка

На macOS проверены загрузка плагина в CanvasTTY, список и фильтр файлов,
переход в подпапку и вверх через кнопки, PNG/JPG/GIF в канвасе, PNG/GIF
в отдельном окне, безопасный текстовый предпросмотр, воспроизведение
H.264/AAC MP4 и PCM WAV в обоих режимах. Двойной клик через текущий
механизм UI-автоматизации не подтверждён; переход кнопкой работает.
Автоматические проверки охватывают разрешения, границы папок, отозванный доступ,
пагинацию, диапазоны байтов и вставку пути в терминал. Ручное перетаскивание
из интерфейса в настоящий терминал, системный диалог выбора папки и кнопка
проводника ещё требуют приёмки. Windows/Linux требуют запуска на этих ОС;
существующая CI-матрица CanvasTTY автоматически подхватит новые тесты.
